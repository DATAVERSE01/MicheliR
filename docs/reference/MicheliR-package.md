# MicheliR: An R Toolkit for the Micheli Guide to Fungal Conservation Policy Gap Assessment

A Shiny-based toolkit for deterministic keyword searches (Fungi,
Animals, Plants) with full audit logs, and optional AI-assisted
(DeepSeek) evaluation using the Micheli Guide framework. It automates
the assessment of CBD National Reports and NBSAPs to identify gaps in
fungal conservation policy.
