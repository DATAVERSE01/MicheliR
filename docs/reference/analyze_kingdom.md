# Analyse a kingdom across document

Analyse a kingdom across document

## Usage

``` r
analyze_kingdom(text, pages, kingdom, lang)
```

## Arguments

- text:

  document lines (character vector)

- pages:

  location labels (same length as text)

- kingdom:

  character: "fungus", "animals", or "plants"

- lang:

  character: "en" or "fr"

## Value

data.frame of matches (or empty)
